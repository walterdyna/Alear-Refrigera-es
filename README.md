# Alear Refrigerações

## Visão Geral do Projeto

Alear Refrigerações é um site institucional desenvolvido para uma empresa especializada em climatização, ar condicionado e refrigeração, atuando principalmente nas regiões do Rio de Janeiro e Espírito Santo. O site apresenta os serviços oferecidos, informações sobre a empresa, clientes parceiros, e um formulário interativo para solicitação de orçamentos via WhatsApp.

O objetivo do projeto é fornecer uma presença online profissional, clara e responsiva, que transmita confiança e excelência nos serviços prestados pela Alear Refrigerações.

---

## Tecnologias Utilizadas

- HTML5 e CSS3 para estrutura e estilo da página.
- JavaScript para interatividade, validação de formulário e integração com WhatsApp.
- Fontes Google Fonts (Inter) para tipografia moderna.
- FontAwesome para ícones visuais.
- Design responsivo para adaptação a diferentes tamanhos de tela.
- Modo escuro (dark mode) com alternância via botão.

---

## Funcionalidades Principais

- **Seções informativas:** Home, Sobre, Serviços, Clientes e Contato.
- **Formulário de contato flutuante:** Permite ao usuário solicitar orçamento, com validação de campos e envio direto para WhatsApp.
- **Modo escuro:** Alternância entre tema claro e escuro para melhor experiência do usuário.
- **Menu responsivo:** Navegação adaptada para dispositivos móveis com menu hambúrguer.
- **Galeria de imagens:** Imagens dos serviços com modal para visualização ampliada.
- **SEO básico:** Uso de meta tags para descrição e palavras-chave.
- **Dados estruturados:** JSON-LD para melhorar a presença em mecanismos de busca.

---

## Estrutura de Arquivos

- `index.html` - Página principal do site com toda a estrutura e conteúdo.
- `styles.css` - Estilos CSS para layout, cores, responsividade e modo escuro.
- `script.js` - Script JavaScript para interatividade, validação do formulário e integração com WhatsApp.
- `robots.txt` - Arquivo para controle de indexação por motores de busca.
- `sitemap.xml` - Mapa do site para facilitar o rastreamento por buscadores.
- `ap.pdf` - Portfólio institucional da empresa com missão, visão, serviços e clientes.
- `assets/` - Pasta contendo imagens e ícones usados no site:
  - Logos, favicon, imagens ilustrativas dos serviços e ícone de atendimento.

---

## Como Usar

1. Clone ou baixe o projeto.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Navegue pelas seções para conhecer a empresa e seus serviços.
4. Utilize o botão "Abrir Formulário" ou o ícone de atendimento para solicitar um orçamento.
5. Preencha o formulário e envie; você será redirecionado para o WhatsApp com a mensagem pronta para envio.
